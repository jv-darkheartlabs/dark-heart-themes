# 7TV install

1. https://7tv.app → **Get Extension**
2. Visit https://twitch.tv/darkheartlabs
3. **Settings → Appearance → Custom CSS** → paste `7tv-anime-gothic-dhl.css`
4. Broadcasters: **7tv.app** dashboard → channel → same CSS for all 7TV viewers

See also `discord/INSTALL.md` and root `README.md`.
